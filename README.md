# PathFuse

**Merge, clean, and visualize your GPX tracks.**

PathFuse lets you upload multiple GPX files from hiking, running, cycling, or other outdoor activities, cleans GPS errors, merges tracks into a smooth route, and displays detailed statistics and similarity scores.


## Tech Stack

- **Next.js** (App Router)  
- **React + Tailwind CSS**
- **Zustand** for state management
- **MapLibre GL JS** for interactive maps 

## Installation

#### 1. Clone the repository
```bash
git clone https://github.com/balintkiraly/path-fuse.git
cd path-fuse
```

#### 2. Install dependencies:
```bash
pnpm install
```

#### 3. Run the development server
```bash
pnpm dev
```

Open http://localhost:3000 in your browser.
